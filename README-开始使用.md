# 钱子恒个人网站 V2：影视感可视化编辑版

这是网站的完整源码。新版采用纯白底、强影像首屏、非对称摄影网格和大字号编辑式排版，并内置独立管理后台，不再依赖 Pages CMS 公共服务。

## 零、自己的后台入口

网站发布后，后台地址是：`https://qianziheng.me/admin/`

后台支持登录、修改全部栏目、调整页面板块顺序、上传图片、增删作品，以及一键“保存并发布”。保存时会自动写入 GitHub，随后由 Netlify 更新正式网站。

首次使用前，在 Netlify 的 **Project configuration → Environment variables** 中添加三个变量：

- `GITHUB_TOKEN`：GitHub fine-grained personal access token，仅授予该网站仓库的 Contents 读写权限。
- `ADMIN_PASSWORD`：你自己设置的后台登录密码。
- `ADMIN_SESSION_SECRET`：用于保护登录状态的随机长字符串，建议至少 32 位。

可选变量：`GITHUB_OWNER`、`GITHUB_REPO`、`GITHUB_BRANCH`。不填写时默认使用当前仓库 `zjgwhxxqzh-netizen/-qianziheng-site-` 的 `main` 分支。

添加变量后，在 Netlify 手动触发一次 **Deploy site**。不要把以上三个密钥写进 GitHub 文件或发给其他人。

## 一、这次可以在后台修改什么

进入自建后台后会看到以下栏目：

1. **网站设置**：修改姓名、邮箱、网站标题、分享封面、强调色、圆角、页面宽度、留白、动效、社交链接和页脚。
2. **页面板块**：可用“上移/下移”调整首屏、摄影、视频、数据亮点、教学、学术、Python、自由介绍、关于我和联系我的先后顺序，也能单独隐藏或复制板块。
3. **首屏主视觉**：可在照片与视频之间切换；视频支持上传 MP4/WebM，或填写 YouTube、哔哩哔哩和 HTTPS 直链，并可设置封面、自动播放、静音、循环和播放控件。
4. **自由图文 / 视频介绍**：这是可重复添加的通用模块，可编辑标题、简介、长正文、引语、图片或视频、按钮、左右排版与底色。
5. **摄影作品**：上传照片，填写名称、分类、地点、署名、说明和跳转链接；每张照片可选择主视觉、横幅、竖图或标准尺寸。摄影板块整体还可切换杂志网格、瀑布流和宽银幕三种布局。
6. **视频作品**：每条视频都可独立设置文件或外链、封面、分类、年份、时长、大小、自动播放、静音、循环、控件与排序；视频板块可切换首条突出、双列网格和单列长卷。
7. **课程教学、学术成果、Python 小程序**：可以新增、删除、排序、隐藏卡片，并修改图片、标签、说明和链接。

## 二、把新版上传到 GitHub

请把压缩包解压后，将里面的所有文件和文件夹上传到现有 GitHub 仓库根目录，选择覆盖同名文件。尤其要确认以下内容上传成功：

- `.pages.yml`
- `build.py`
- `assets` 文件夹
- `content` 文件夹
- `netlify.toml`

`dist` 是已经构建好的网页，也可以一起上传。原仓库中的旧 `template.html` 即使保留也不会影响新版网站。

## 三、让公开网站自动更新

现有 Netlify 项目应当连接到这个 GitHub 仓库，并保持以下设置：

- Build command：`python3 build.py`
- Publish directory：`dist`

每次在自建后台点击“保存并发布”后，内容会写入 GitHub；Netlify 会自动重新构建。通常等待一两分钟，再用 `Ctrl + F5` 强制刷新 `https://qianziheng.me`。

## 四、第一次进入后台建议先做的事

1. 打开“网站设置”，填写联系邮箱和社交主页链接。
2. 展开“首屏主视觉”，上传一张代表性照片。
3. 进入“摄影作品”，依次打开已经准备好的五个分类卡片，上传真实作品。
4. 如果要使用视频，进入“视频作品”修改示例条目并打开“在网页显示”，然后回到“页面板块”打开“视频作品板块”的显示开关。
5. 根据照片横竖比例修改“单张照片占位大小”，再回到摄影板块切换整体排版进行比较。
6. 如需增加新的个人介绍，在“页面板块”中新建或复制“自由图文 / 视频介绍板块”，设置不同的英文锚点并拖动到需要的位置。
7. 在课程和学术栏目补充真实链接；没有链接时可以留空，网页不会显示空按钮。

## 五、图片建议

- 首屏照片：建议接近 4:5，长边 1800—2400 像素。
- 横幅照片：建议 16:9；竖图建议 3:5 或 4:5。
- 优先使用 JPG 或 WebP，单张尽量控制在 2 MB 以内。
- 不要上传证件、学生隐私材料或未经授权的人像。

## 六、视频建议

- 背景循环视频建议 8—20 秒、静音、MP4 格式，尽量控制在 20 MB 以内。
- 较长的视频不要直接放进 GitHub；上传到 YouTube 或哔哩哔哩后填写链接，网页会自动使用播放器。
- 自动播放通常必须同时打开“默认静音”，这是浏览器的正常限制。
- 每条视频都建议上传一张 16:9 封面图，网速较慢时页面仍然美观。

## 七、本地预览（可选）

安装 Python 3 后，在项目根目录运行：

```bash
python3 build.py
```

网页会生成到 `dist/index.html`，双击即可查看。本项目只使用 Python 标准库，不需要安装额外依赖。
