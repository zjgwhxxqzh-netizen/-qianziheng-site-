# 钱子恒个人网站 V2：影视感可视化编辑版

这是网站的完整源码。新版采用纯白底、强影像首屏、非对称摄影网格和大字号编辑式排版，并把页面的大部分文字、板块顺序和布局选项开放到 Pages CMS 后台。

## 一、这次可以在后台修改什么

进入 Pages CMS 后会看到五个栏目：

1. **网站全局与页面布局**：修改姓名、邮箱、导航、网站标题、强调色、圆角、留白、动效、社交链接和页脚。
2. **页面板块**：在“网站全局与页面布局”里展开“页面板块”，可拖动调整首屏、摄影、数据亮点、教学、学术、Python、关于我和联系我的先后顺序，也能单独隐藏板块。
3. **摄影作品**：上传照片，填写名称、分类和说明；每张照片可选择主视觉、横幅、竖图或标准尺寸。摄影板块整体还可切换杂志网格、瀑布流和宽银幕三种布局。
4. **课程教学、学术成果、Python 小程序**：可以新增、删除、排序、隐藏卡片，并修改图片、标签、说明和链接。

## 二、把新版上传到 GitHub

请把压缩包解压后，将里面的所有文件和文件夹上传到现有 GitHub 仓库根目录，选择覆盖同名文件。尤其要确认以下内容上传成功：

- `.pages.yml`
- `build.py`
- `assets` 文件夹
- `content` 文件夹
- `netlify.toml`

`dist` 是已经构建好的网页，也可以一起上传。原仓库中的旧 `template.html` 即使保留也不会影响新版网站。

## 三、让公开网站自动更新

现有 Netlify 项目应当连接到这个 GitHub 仓库，并保持以下设置：

- Build command：`python3 build.py`
- Publish directory：`dist`

每次在 Pages CMS 保存后，它会把内容写入 GitHub；Netlify 会自动重新构建。通常等待一两分钟，再用 `Ctrl + F5` 强制刷新 `https://qianziheng.me`。

## 四、第一次进入后台建议先做的事

1. 打开“网站全局与页面布局”，填写联系邮箱和社交主页链接。
2. 展开“首屏主视觉”，上传一张代表性照片。
3. 进入“摄影作品”，依次打开已经准备好的五个分类卡片，上传真实作品。
4. 根据照片横竖比例修改“单张照片占位大小”，再回到摄影板块切换整体排版进行比较。
5. 在课程和学术栏目补充真实链接；没有链接时可以留空，网页不会显示空按钮。

## 五、图片建议

- 首屏照片：建议接近 4:5，长边 1800—2400 像素。
- 横幅照片：建议 16:9；竖图建议 3:5 或 4:5。
- 优先使用 JPG 或 WebP，单张尽量控制在 2 MB 以内。
- 不要上传证件、学生隐私材料或未经授权的人像。

## 六、本地预览（可选）

安装 Python 3 后，在项目根目录运行：

```bash
python3 build.py
```

网页会生成到 `dist/index.html`，双击即可查看。本项目只使用 Python 标准库，不需要安装额外依赖。
